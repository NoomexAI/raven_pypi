Build document assistants with answers you can inspect.

RAVEN is an open-source RAG framework for developers building assistants around their own documents. Agent-directed retrieval, source reconstruction, and persistent conversations, in a backend you can use from Python or connect to your own interface.

pip install noomexai-raven

From a question to something you can check

An answer alone leaves the reader with another question: where did that come from? With RAVEN, your application can show the search the model performed and the document sections supplied to it, highlighted within their surrounding content.

Let the model investigate

A precise specification, a narrative explanation, and a question spanning several documents call for different searches. RAVEN gives the agent retrieval tools it can choose and use in sequence, instead of forcing every question through one fixed search step.

Let it choose among the strategies or restrict a turn to one. Focus a conversation on a single knowledge, or explore the whole knowledge base.

You control the available tools and scope; the model decides how to work within them.

Let the reader check the source

A source reference tells someone where to look. RAVEN’s source reconstruction helps them see what to look at: the sections supplied to the model, highlighted inside a readable reconstruction of the file.

Your application can put the answer and its supporting material side by side, without asking the reader to hunt through an entire document. For documents with preserved page ranges, your interface can link back to the original pages.

The highlights show what the model received, not a guarantee that every claim in its answer is correct. They make checking possible rather than replacing it.

Keep the conversation going

Working with documents rarely ends at the first answer. People clarify a detail, connect it to another file, or return later with a new question.

RAVEN keeps conversation history, including tool interactions, and gives the agent memory tools for recalling earlier discussions. Your interface can stream the response, show tool activity, and display sources as they become available.

  • History that includes tool useMessages, tool calls, and results are persisted with each turn.
  • Memory the agent can searchEarlier discussion stays recallable as conversations grow.
  • Context compactionLonger conversations fit the model’s context without losing the full transcript.
  • Saved preferencesEach conversation can be tuned to the person using it.

From documents to a checkable answer

Four steps, all through one Python API.

  1. Install

    Install the package from PyPI, plus a running Ollama server if you want local models.

  2. Configure

    Pick one LLM and one embedding model: local through Ollama, cloud through LiteLLM, or a mix.

  3. Ingest

    Add .txt, .md, .pdf, or .docx files. RAVEN parses, sections, and embeds them.

  4. Ask

    Start a conversation, stream the events, and show the reader the sources behind the answer.

Your application, your models

Build a desktop research workspace, add a document assistant to an existing Python application, or connect a web interface through your own backend. RAVEN provides the document and conversation machinery; it does not prescribe a frontend.

Python or HTTP

Use the Raven class directly, or run the optional FastAPI server with bearer authentication and Server-Sent Events for a browser or desktop UI.

Local or cloud models

Run models locally through Ollama, use supported cloud models through LiteLLM, or choose a different provider for each role.

Observable, recoverable work

Long-running work has status, replayable events, cancellation, and explicit retry for eligible tasks. Interrupted operations are detected after a restart.

Data you keep

Knowledge, conversations, and vectors live in a directory you control, isolated per user. Pair it with local models to keep inference local too.
